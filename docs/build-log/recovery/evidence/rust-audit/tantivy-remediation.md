# Tantivy 0.27 resolves the new compression advisories

Release CI run 40334672703, job 121613033913, failed on RUSTSEC-2026-0391, 0398, 0403 and 0410. The prior audit passed before RustSec assigned these records at 2026-10-26T13:45:01Z in [advisory-db commit a78282a](https://github.com/RustSec/advisory-db/commit/a78282a1414d6c28cc228c4eae3570451affb0dc). A structural comparison confirms all 794 non-workspace package entries were identical between main `2b8d4801` and release checkpoint `47305d22`; the release lockfile synchronization changed only the 18 workspace versions.

Tantivy 0.26.2 still requires the 0.7 SSTable and Zstd 0.13 lines. The registry lists no newer 0.7 SSTable patch. The ordinary published fix is Tantivy 0.27.0, whose dependency line resolves to `tantivy-sstable 0.27.0`, `zstd 0.14.3`, `zstd-safe 8.2.0` and `zstd-sys 2.1.2`. The workspace requirement changes from `0.26` to `0.27`; no application Rust code or public protocol changes were needed. Disabling columnar Zstd support was rejected because existing compressed SSTable blocks would become unreadable without that feature.

Primary records: [0391](https://rustsec.org/advisories/RUSTSEC-2026-0391), [0398](https://rustsec.org/advisories/RUSTSEC-2026-0398), [0403](https://rustsec.org/advisories/RUSTSEC-2026-0403), [0410](https://rustsec.org/advisories/RUSTSEC-2026-0410), [Tantivy 0.27 changelog](https://github.com/quickwit-oss/tantivy/blob/0.27.0/CHANGELOG.md), and registry dependency endpoints for [Tantivy](https://crates.io/api/v1/crates/tantivy/0.27.0/dependencies), [SSTable](https://crates.io/api/v1/crates/tantivy-sstable/0.27.0/dependencies), [Zstd](https://crates.io/api/v1/crates/zstd/0.14.3/dependencies) and [Zstd-safe](https://crates.io/api/v1/crates/zstd-safe/8.2.0/dependencies).
